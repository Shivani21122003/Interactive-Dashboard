# Titanic Survival Interactive Dashboard

## Project Overview
This project presents an interactive dashboard created using Microsoft Power BI to analyze passenger survival patterns in the Titanic dataset. It was developed as part of my internship at SWYNEX Technologies.

## Objectives
- Analyze Titanic passenger survival data.
- Present important information using KPI cards.
- Compare survival rates by gender and passenger class.
- Provide interactive filters for exploring the data.

## Tools Used
- Microsoft Power BI
- Titanic dataset
- Data visualization and analysis

## Dashboard KPIs
- **Total Passengers:** 1,310
- **Total Survivors:** 501
- **Overall Survival Rate:** 38.24%
- **Average Fare:** 33.28

## Visualizations
- Survival Rate by Gender
- Survival Rate by Passenger Class

## Interactive Filters
- Gender
- Passenger Class
- Embarkation Port

## Key Insights
- Female passengers had a higher survival rate than male passengers.
- First-class passengers had a higher survival rate than second- and third-class passengers.
- Approximately 38.24% of passengers survived.
